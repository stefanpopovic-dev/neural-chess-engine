    How it works

    Search

    Negamax alpha-beta with iterative deepening, a quiescence search over captures, and move ordering by previous best move, MVV-LVA captures and checks, all built on python-chess. It plays the best move from the last depth it fully finishes before the time runs out.

    Evaluation network

    A 781 → 256 → 32 → 1 network trained in PyTorch on one million positions from Lichess games, each scored by Stockfish 19. Here it runs with numpy inside a Vercel serverless function, with a Zobrist-keyed cache of evaluations.

    Results

    Against the same search judging by material count, the network version scored +73 =21 −6 (about +280 Elo) over 100 games, despite searching a ply shallower. Both are still far weaker than a real engine like Stockfish.
